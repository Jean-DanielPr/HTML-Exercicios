Exemplo 25 HTML CSS - Formas de Vinculação de arquivos CSS

Existem duas formas básicas de vinculação de arquivos CSS em documentos HTML, essas formas são a interna e a externa. Neste exemplo vamos demonstrar a vinculação externa, que é aquela onde criamos ou utilizamos um arquivo CSS externo.

A vinculação externa apresenta uma série de vantagens em relação a vinculação interna de arquivos CSS. Dentre as vantagens podemos citar:

  • Facilidade de manutenção: isso ocorre pois você edita apenas um arquivo CSS que é aplicado a todos os arquivos que o utilizarem.
  • Reutilização de código: um único código ou arquivo de estilo pode ser ligado a dezenas ou centenas de páginas HTML.
  • Carregamento mais raápido: o navegador guarda em cache o arquivo CSS caregado o que aumenta a velocidade de carregamento da página HTML.
  • Organização de código: quando utilizamos arquivos CSS externos ele fica separado do arquivo HTML o que facilita a nálise, organização e manutenção destes arquivos.

Vinculação Externa

A vinculação externa é a forma mais recomendada, neste caso o CSS é uma parte que pode ser criado pelo desenvolvedor ou um arquivo de um grupo, como exemplo o FrameWork Bootstrap. Neste caso, para vincular o arquivo externo devemos usar a tag link.

Neste exemplo, estamos usando uma arquivo externo para estilizar todos os nosso elementos. Ou seja, nesse arquivo externo temos nossas regras de estilização que serão aplicadas a este documento ou qualquer outro. É importante frisar que a vinculação externa é a mais recomendada pois facilita a manutenção e o reuso do arquivo.
