# 💻 Exercícios de Desenvolvimento de Interfaces

Este repositório foi criado para armazenar e organizar todos os exercícios, atividades e projetos práticos desenvolvidos durante a disciplina de **Desenvolvimento de Interfaces** na faculdade.

O objetivo principal é praticar os conceitos fundamentais do desenvolvimento web *front-end*, registrando minha evolução acadêmica e construindo uma base prática sólida.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica de páginas web.
- **CSS3:** Estilização, *layouts* responsivos e design de interfaces.
- **JavaScript:** Interatividade, manipulação do DOM e lógica para a web.
